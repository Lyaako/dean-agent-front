# Решения и допущения при реализации

Этот журнал фиксирует решения, которые я принимаю после разрешения пользователя от 11 октября 2026: «каждое решение дальше кроме критичных принимай сам, но записывай каждое решение и допущение в отдельный файл, но строго придерживайся плана». Подтверждённые пользователем решения находятся в [финальном плане](DETAILED_IMPLEMENTATION_PLAN.md), [контрактах](CHAT_API_CONTRACT.md) и [OPEN_DECISIONS.md](OPEN_DECISIONS.md). При конфликте действует прямое решение пользователя и финальный план. Критичные изменения функционального объёма, удаления данных или границ доступа требуют отдельного подтверждения.
