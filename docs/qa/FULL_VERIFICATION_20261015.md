## Условия

Основной стенд — `http://localhost:8443`, проект `deanery-p13`. Для проверок с записью поднят отдельный видимый стенд `http://localhost:58043` с новой синтетической БД, отдельными файлами, очередями и Qdrant. На нём использованы пять существующих тестовых учётных записей; пароли пользователей основного стенда не сбрасывались. Тестовые приказы, оценки, стипендии и удаления относятся только к этому отдельному стенду.

Разработка продолжена с Codex; агент проверялся с настоящей `qwen_qwen3.5-9b` Q4_K_M через LM Studio, context20480, parallel1, temperature0.6, reasoning_effort=none, max_tokens1536. Поиск использовал настоящие BAAI/BGE-M3 dense/sparse и Qdrant1.15.5. Испытания выполнены на Windows11, Python3.13, Docker Desktop/Linux и PostgreSQL17, с русским/английским Tesseract; локальная машина — RTX4060 Laptop8ГБ и16ГБ RAM. Системный prompt и схемы14 инструментов не менялись, ранее измеренная калибровка4483 статических токенов остаётся применимой.

## Два исправления бэкенда

1. Пакетное предложение обнуляло экран старого React: карточка ожидала changed_columns, которого не было в BATCH. Добавлен общий контракт представления для HTTP, истории и SSE. Он сохраняет исходные items и показывает before/after отдельно для каждой строки; контроль разрешённых полей и выбранных строк не ослаблен. Повторный просмотр карточки кликом успешен, выбор/исполнение/повтор/undo проверены HTTP. Регрессия проверяет равенство HTTP/SSE и отсутствие потери строк.
2. PDF с множеством коротких страниц занимал почти весь лимит фрагментов до TXT/DOCX. Начальная загрузка теперь оставляет место следующим файлам и запрашиваемой странице; при исчерпанном лимите можно повторно прочитать уже известные проверенные байты. Общие лимиты/хеши/контекст провайдера сохранены. Тот же запрос с теми же3 файлами повторён через UI: все контрольные значения и3 подтверждённые цитаты получены, посторонние инструкции проигнорированы. Добавлены проверки резерва и повторного чтения без расширения бюджета.
